# Being Heumann — AP Lang Style Practice

A 50-question, AP English Language & Composition–style multiple-choice practice quiz covering the **Prologue through Chapter 3** ("To Fight or Not to Fight") of Judith Heumann's memoir *Being Heumann: An Unrepentant Memoir of a Disability Rights Activist* (with Kristen Joiner).

**Live site:** https://sunlitkoreakorea.github.io/being-heumann-ap-lang-quiz/

## What it covers

| Section | Questions |
|---|---|
| Prologue | 6 |
| Chapter 1 — The Butterfly | 16 |
| Chapter 2 — Insubordinate | 14 |
| Chapter 3 — To Fight or Not to Fight | 14 |

Each question targets AP Lang–style rhetorical-analysis skills: diction and connotation, tone, syntax, figurative language, structure and organization, rhetorical appeals, allusion, and argumentative strategy — with an explanation provided for every answer.

## Features

- Instant-feedback or exam-style modes
- Optional question/answer shuffling
- Per-chapter score breakdown
- Full post-quiz review with a "missed only" filter
- Light/dark theme, mobile-friendly layout
- No build step, no dependencies — a single static `index.html`

## Note on the source text

This is an original study aid written for independent exam preparation. Question stems paraphrase and lightly quote (a few words at a time) the memoir for commentary and educational purposes; it does not reproduce the book's text. Readers should read *Being Heumann* itself for the full story.
